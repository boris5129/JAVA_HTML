SQL 오류 메시지 해석 방법테이블 미존재 (Error 1146 - Table doesn't exist)   원인: 철자 오타나 복수형(s) 누락으로 해당 테이블을 찾을 수 없을 때 발생합니다 (예: restaurant $\rightarrow$ restaurants).   컬럼 미존재 (Unknown column)   원인: 존재하지 않는 컬럼명을 SELECT나 WHERE 절에 적었을 때 발생합니다.   문법 오류 (SQL syntax error around 'near...')   원인: 쉼표(,) 누락, 예약어 오타 등 문법적 오류가 있을 때 발생합니다. 에러 메시지의 near 뒷부분 바로 앞을 살펴보면 오타를 찾을 수 있습니다.   2. SELECT 문의 동작 원리 (치환과 반복문)새로운 표(Table)를 그리는 행위:SELECT는 원본 테이블을 바꾸는 것이 아니라, 기존 테이블의 데이터를 한 행씩 읽어와(반복문) 새로운 결과 표를 조합·치환하여 출력하는 연산입니다.   컬럼 연산:SELECT price * 1.1, price - 1000과 같이 컬럼 값에 산술 연산을 적용하여 가공된 새로운 열로 만들 수 있습니다.   3. 별칭(Alias, AS)의 사용법 및 주의점역할: 조회 결과의 컬럼명을 원하는 이름으로 바꿀 때 사용합니다 (예: price AS new_price).   쉼표 누락으로 인한 의도치 않은 별칭 버그:AS를 생략하고 공백만으로도 별칭 지정이 가능하기 때문에, SELECT name, price에서 쉼표가 빠져 SELECT name price가 되면 에러 없이 name 컬럼의 별칭이 price로 바뀌어 출력되는 심각한 실수가 발생합니다.   따라서 컬럼 별칭을 쓸 때는 실수 방지를 위해 반드시 AS를 명시하는 것이 좋습니다.   4. 중복 제거 (DISTINCT)역할: 조회 결과 행에서 중복된 값을 걸러내고 고유한 값만 출력합니다.   기준: 단일 컬럼뿐만 아니라 여러 컬럼을 지정할 경우(DISTINCT category, district), 나열된 모든 컬럼 값의 조합이 완벽히 일치할 때를 기준으로 중복을 제거합니다.   5. WHERE 절과 조건 검색행(Row) 단위 필터링:WHERE 절은 특정 칸(셀)을 고르는 것이 아니라, 조건이 참(TRUE)인 행 전체를 통째로 걸러내는 역할을 합니다.   비교 연산자:같음: = (SQL에서는 조건식에서 =가 비교 연산자로 사용됨)   다름: <> 또는 !=   논리 연산자 (AND, OR) 및 괄호의 중요성:AND가 OR보다 연산 우선순위(곱셈과 덧셈의 관계)가 높습니다.   복합 조건을 구성할 때는 의도한 대로 먼저 계산되도록 반드시 소괄호 ()를 사용해야 합니다.   범위 검색 (BETWEEN A AND B):$A$ 이상 $B$ 이하를 뜻하며 양 끝값을 포함(Inclusive)합니다.   시간 정보가 없는 날짜 리터럴의 경우 00:00:00 기준이 되므로 범위 설정에 주의해야 합니다.   목록 포함 (IN / NOT IN):나열된 값 중 하나라도 포함되는지 확인합니다 (예: category IN ('한식', '일식')).   패턴 검색 (LIKE와 와일드카드):   %: 글자 수 제한 없는 모든 문자   '치킨%': 치킨으로 시작   '%치킨': 치킨으로 끝남   '%치킨%': 치킨 포함   _: 정확히 1글자   '_밀면_': 앞뒤로 한 글자씩 있는 총 4글자   NULL 비교 (IS NULL / IS NOT NULL):NULL은 값이 없는 상태이므로 = NULL이나 != NULL 같은 비교 연산자를 쓸 수 없으며, 반드시 IS NULL 또는 IS NOT NULL 키워드를 사용해야 합니다.   6. 정렬 (ORDER BY)역할: 조회된 결과 행의 순서를 지정합니다.   정렬 방식:오름차순 (ASC): 작은 값부터 큰 값으로 (1 $\rightarrow$ 10, 가 $\rightarrow$ 하, A $\rightarrow$ Z), 기본값이므로 생략 가능.   내림차순 (DESC): 큰 값부터 작은 값으로.   한글 씹힘/띄어쓰기 팁 (전각/반각 문제):윈도우 작업표시줄의 한/영 입력기 상태가 '전각'으로 바뀌면 글자 폭이 비정상적으로 벌어지거나 타이핑 오류가 날 수 있으므로 우클릭하여 '반자'로 변경해야 합니다
