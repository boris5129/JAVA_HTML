SQL syntax error (near...): 쉼표(,) 누락, 문법 구조 오류 시 발생하며, 에러 메시지의 near 바로 앞뒤 단어를 점검해야 합니다.   2. SELECT 구문의 동작 원리와 별칭(Alias)새로운 표의 치환/생성: SELECT는 원본 데이터를 바꾸는 것이 아니라, 테이블에서 조건에 맞게 데이터를 한 줄씩 읽어와 가상의 표로 새로 만들어 출력하는 반복문 구조입니다.   AS 키워드: 컬럼명을 바꿀 때 사용하며, 공백으로도 별칭 지정이 가능하기 때문에 쉼표(,)가 빠지면 뒤의 컬럼명이 앞 컬럼의 별칭으로 바뀌어 출력되는 실수가 잦아 AS를 명시하는 것이 권장됩니다.   3. 중복 제거 (DISTINCT)결과 행 전체를 기준으로 중복을 걸러내며, 여러 컬럼을 함께 적으면 명시된 모든 컬럼의 조합이 일치할 때 중복으로 간주하고 제거합니다.   4. WHERE 절과 조건식행(Row) 단위 필터링: 칸(Cell) 단위가 아니라 조건이 참(TRUE)인 행 전체를 골라내는 절입니다.   연산자 및 우선순위:같음은 =, 다름은 <> 또는 !=를 사용합니다.   AND 연산이 OR보다 우선순위가 높으므로 복합 조건식에는 소괄호 ()를 필수로 묶어야 합니다.   BETWEEN A AND B: $A$ 이상 $B$ 이하(양 끝값 포함)를 의미하며, 날짜 비교 시 시간 정보(00:00:00)에 유의해야 합니다.   IN / NOT IN: 나열된 목록 중 포함 여부를 확인합니다.   IS NULL / IS NOT NULL: NULL 값 비교 시에는 = 기호 대신 해당 키워드를 사용해야 합니다.   5. 정렬 (ORDER BY)ASC(오름차순, 기본값)와 DESC(내림차순)를 사용해 결과 행의 순서를 정렬합니다.   쿼리 내부 처리 순서상 FROM → WHERE → SELECT → ORDER BY 순으로 실행되기 때문에 WHERE 절에서는 SELECT에서 정의한 별칭을 참조할 수 없습니다.
