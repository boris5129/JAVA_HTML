SQL 언어의 분류: TCL과 DCLTCL (Transaction Control Language, 트랜잭션 제어어):트랜잭션(여러 세부 작업을 쪼갤 수 없는 하나의 논리적 단위로 묶는 것, 예: 은행 계좌 이체)을 확정(COMMIT)하거나 취소(ROLLBACK)하여 일괄 관리하는 명령어입니다.   DCL (Data Control Language, 데이터 제어어):특정 사용자에게 데이터베이스/테이블에 대한 접근 및 조작 권한을 부여(GRANT)하거나 회수(REVOKE)하는 명령어입니다.   2. 관계형 데이터베이스(RDBMS) 기본 개념RDBMS: 데이터를 행(Row)과 열(Column)로 구성된 2차원 표(Table) 형태로 체계화하고 테이블 간의 관계(Relationship)를 맺어 관리하는 시스템입니다.   테이블 구조:행 (Row / Record): 하나의 데이터 개체 정보를 나타냅니다.   열 (Column / Field): 데이터의 속성과 자료형(타입)을 정의합니다.   키(Key)의 기본 역할:고유 식별 번호(ID)를 기본키(PK) 및 외래키(FK)로 활용해 고객 테이블과 주문 테이블 등을 연결(조합)하여 데이터를 관리합니다.   3. 문자셋(Charset)과 콜레이션(Collation)utf8mb4:기존 UTF-8(최대 3바이트, mb3)과 달리 최대 4바이트까지 지원하여 이모지(이모티콘, Emoji)와 다양한 유니코드 문자를 깨짐 없이 완벽하게 저장할 수 있습니다.   _ci (Case Insensitive):문자셋 설정 뒤에 _ci가 붙어 있으면 영문 데이터 조회 및 비교 시 대소문자를 구분하지 않는다는 의미입니다.   4. 필수 명령어 및 SQL 작성 규칙USE [데이터베이스명];:작업할 데이터베이스를 현재 활성 상태로 선택하는 필수 명령어입니다. (이 명령을 실행하지 않고 쿼리를 날리면 No database selected 에러가 발생합니다).   SHOW TABLES; / SHOW DATABASES;: 목록을 확인할 때 사용하며 항상 복수형(s)을 사용합니다.   DESC [테이블명]; (DESCRIBE): 해당 테이블의 스키마 구조(컬럼명, 데이터 타입, Null 여부, Key 등)를 확인합니다.   SQL 표기 및 작성 규칙:대소문자 컨벤션: 예약어(명령어)는 대문자, 테이블명이나 컬럼명은 소문자로 쓰는 것이 표준 관례입니다.   문자열/날짜 리터럴: 큰따옴표(")가 아니라 반드시 작은따옴표(')로 묶어야 표준 SQL 규격에 부합합니다.   문장 종료: 모든 SQL 문장은 세미콜론(;)으로 끝맺어야 합니다.   단축키: 워크벤치에서 한 줄 실행은 Ctrl + Enter, 선택 영역 또는 전체 실행은 Ctrl + Shift + Enter입니다.
