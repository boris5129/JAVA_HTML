HTML 테이블 기본 태그 구조<table>: 전체 표 영역을 감쌉니다.   <thead> / <th>: 표의 제목 영역(헤더)으로, 번호·상품명·가격 등 컬럼명을 정의합니다.   <tbody>: 실제 데이터가 들어가는 본문 영역입니다.   <tr>: 표의 가로 행(Row, 한 줄)을 의미합니다.   <td>: 각 행 안에 들어가는 실제 데이터 셀(칸)입니다.   2. 백엔드 서블릿(Servlet)의 상품 목록 응답 (GET 요청)목록 조회 요청 수신:동일한 URL(/api/products)이라도 데이터 조회를 위한 요청은 HTTP GET 방식(doGet)으로 처리합니다.   POST와 달리 클라이언트가 별도의 Body 데이터를 보내지 않으므로, 백엔드는 저장소에서 목록 데이터를 준비합니다.   Jackson 직렬화 및 전송:상품 객체 리스트(List<Product>)를 생성한 뒤, Jackson 라이브러리의 ObjectMapper.writeValueAsString()을 사용해 JSON 문자열로 변환합니다.   한글 깨짐 방지와 데이터 형식 지정을 위해 response.setContentType("application/json; charset=UTF-8")을 설정합니다.   response.getWriter().println(jsonString)으로 클라이언트에게 JSON 문자열을 내려줍니다.   주의사항: Jackson 라이브러리가 객체를 다룰 수 있도록 모델 클래스에는 기본 생성자(NoArgsConstructor)와 전체 필드 생성자(AllArgsConstructor), Getter/Setter가 갖춰져 있어야 합니다.   3. 프론트엔드 비동기 통신과 동적 화면 렌더링페이지 로드 시 자동 호출:페이지가 열리자마자 목록을 보여주기 위해 비동기 함수(getProductList())를 즉시 실행합니다.   fetch 요청 및 JSON 파싱:fetch('/api/products')로 GET 요청을 보냅니다.   응답 객체에서 response.json()을 호출하면 JSON 파싱(문자열 → 자바스크립트 배열/객체 변환)이 한 번에 처리됩니다.   map()을 활용한 HTML 동적 생성:서버로부터 받아온 데이터 배열을 array.map()으로 반복 돌려 각 요소를 <tr><td>...</td></tr> 형태의 HTML 문자열로 치환합니다.   생성된 태그 문자열들을 <tbody>의 내부(innerHTML)에 주입하여 브라우저 화면에 표로 출력합니다.   4. 프론트엔드와 백엔드의 역할 분담프론트엔드: 사용자 입력을 받아 API로 요청을 전송하고, 백엔드로부터 받아온 순수 데이터(JSON)를 화면에 빠르고 자연스럽게 렌더링하는 역할을 담당합니다.   백엔드: 비즈니스 로직 처리, 데이터베이스 연동 및 관리, 요청 필터링, 보안 검증, 캐싱(자주 찾는 데이터를 가까운 곳에 임시 보관해 응답 속도를 높이는 작업) 등을 담당합니다.
