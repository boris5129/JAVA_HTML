SELECT 문의 본질: 가상 표(Table) 생성 및 반복문새로운 표를 만드는 행위: SELECT는 단순히 데이터를 보여주는 것에 그치지 않고, 기존 테이블에서 데이터를 한 줄씩 읽어와(For-each 반복문 개념) 새로운 가상의 결과 표를 생성·치환하는 연산입니다.   컬럼 연산: 조회할 때 SELECT price, price * 1.1, price - 1000처럼 컬럼 값에 산술 연산을 바로 적용하여 새로운 열(Column)로 출력할 수 있습니다.   2. 별칭(Alias, AS)의 역할과 주의점역할: 조회되는 결과 표의 컬럼명을 변경하고 싶을 때 AS [별칭]을 사용합니다 (예: SELECT menu_name AS name).   AS 키워드 생략의 위험성:AS를 생략하고 공백으로 SELECT name price처럼 쓰면 문법적으로는 동작하지만, 쉼표(,) 누락 시 의도치 않게 name 컬럼의 별칭이 price로 지정되는 논리 오류가 발생하기 쉽습니다.   따라서 컬럼 별칭을 지정할 때는 가독성과 실수 방지를 위해 AS를 명시하는 것이 권장됩니다.   3. 중복 제거 (DISTINCT)문법: SELECT DISTINCT [컬럼명] FROM [테이블명];   동작 원리:한 컬럼만 지정하면 해당 컬럼의 중복 값을 제거합니다 (예: 카테고리 종류만 모아볼 때).   여러 컬럼을 함께 지정(DISTINCT district, category)하면, 명시된 모든 컬럼의 조합이 완전히 일치하는 행을 기준으로 중복을 제거합니다.   4. 행(Row) 필터링: WHERE 절의 기본 원리행 단위 필터링: WHERE는 특정 데이터 칸(Cell)을 골라내는 것이 아니라, 조건이 참(TRUE)인 행(Row/Record) 전체를 걸러내는 절입니다.   실행 순서: FROM (테이블 지정) → WHERE (조건에 맞는 행 필터링) → SELECT (원하는 컬럼 선택 및 연산) 순으로 내부 처리됩니다.   5. WHERE 절 조건식 및 연산자비교 연산자:같음: = (조건식에서는 대입이 아닌 비교)   다름: <> 또는 !=   논리 연산자 우선순위 (AND vs OR):AND가 OR보다 연산 우선순위가 높기 때문에, 여러 조건을 복합해서 사용할 때는 반드시 소괄호 ()를 사용해 우선순위를 명확히 묶어주어야 합니다.   범위 검색 (BETWEEN A AND B):A와 B를 모두 포함(이상 ~ 이하, Inclusive)합니다.   날짜 검색 시 주의: BETWEEN '2026-06-01' AND '2026-06-30'으로 지정하면 끝 날짜의 시간 정보가 기본값인 00:00:00으로 처리되어, 6월 30일 중 발생한 데이터(예: 30일 낮 주문)가 누락될 수 있으므로 시간 범위까지 주의해야 합니다.   목록 포함 여부 (IN / NOT IN):특정 컬럼 값이 나열된 목록 중 하나라도 일치하는지 확인할 때 사용합니다 (예: status IN ('배달완료', '취소')).   부정 연산자 NOT의 위치:연산자 기호 앞(예: NOT (price = 10000))에 붙이거나,   키워드 기반 연산자 앞(예: NOT IN (...), NOT BETWEEN ...),   또는 IS NOT NULL처럼 문법적 어순에 맞게 위치시켜야 합니다.
