1. 프론트엔드 이벤트 핸들러 명명 규칙명명 패턴: handle + [대상/기능] + [이벤트 종류] 형태로 작성하여 가독성을 높입니다.   등록 버튼 클릭: handleRegisterButtonOnClick   상품명 입력 키 이벤트: handleProductNameInputOnKeyUp   가격 입력 키 이벤트: handlePriceInputOnKeyUp   매개변수 컨벤션: 이벤트 객체를 받을 때 보통 e 또는 event로 축약하여 사용합니다.   2. Fetch API를 통한 데이터 전송 (POST 요청)데이터 수집: 인풋 요소(productName, price)에 입력된 값을 가져와 자바스크립트 객체 형태로 묶습니다.   JSON 직렬화: 자바스크립트 객체 그대로는 전송할 수 없으므로 JSON.stringify()를 사용해 JSON 문자열로 변환합니다.   요청 헤더 설정: 서버가 JSON 데이터임을 인식할 수 있도록 headers에 'Content-Type': 'application/json'을 명시합니다.   전송: fetch('/api/products', { method: 'POST', ... })를 통해 서버로 요청을 보냅니다.   3. 백엔드 서블릿(Servlet) 수신 및 Jackson 파싱서블릿 매핑: @WebServlet("/api/products") 경로로 매핑된 서블릿에서 doPost() 메서드로 요청을 수신합니다.   요청 본문(Body) 읽기:request.getReader() 또는 BufferedReader를 사용하여 클라이언트가 보낸 JSON 문자열 스트림을 읽어옵니다.   Jackson 라이브러리를 통한 객체 매핑:문자열을 일일이 파싱(문자열 자르기 등)하지 않고, Jackson 라이브러리의 ObjectMapper를 활용합니다.   objectMapper.readValue(..., Product.class) 메서드를 호출하여 JSON 문자열을 Java Product 객체로 자동 변환(역직렬화)합니다.   DTO/Model 클래스 위치 주의사항:Jackson 라이브러리(외부 라이브러리)가 리플렉션을 통해 객체를 생성하고 접근할 수 있어야 합니다.   서블릿 메서드 내부의 로컬 클래스로 선언하면 접근 권한 문제로 인식이 되지 않으므로, 별도의 독립된 클래스(DTO/Model 패키지)로 분리하고 public으로 선언해야 정상 동작합니다.
