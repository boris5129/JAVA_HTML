테이블 설계
create 'x' 이름 으로 구조를 만든다.
컬럼명 + 자료형 + null 처리  
id 값을 primary key로 많이씀 
PK에 AUTO_INCREMENT 거의 쓴다.
유니크 - 1:1 매칭이 될수있게 한다.
CONSTRAINT - FOREIGN KEY 세팅 과 CHECK
CONSTRAINT + 이름 + 제약(check) + 조건

CONSTRAINT `fk_reviews_order` FOREIGN KEY (`order_id`) REFERENCES `orders` (`order_id`),
reviews에 넣는 order_id는 orders에 존재하는 order_id여야 한다

CHECK, PRIMARY KEY, FOREIGN KEY  위(create table) 에 해도되는데 복잡해진다.

자료형
TINYINT  - java의 byte 1byte
INT - 4byte int
BIGINT - long 8byte

DECIMAL - 소수점 DECIMAL(자리수, 소수점)

중간테이블 (2정규되어져 있는 테이블)

VARCHAR(n) - 빈공간 삭제 필요한만큼 ex) 6칸에 1 = 1 
차이 
CHAR(n) - 자리수 고정  ex) 6칸에 1 = 000001
text - 두개가 못담는거 text 에도 long midle 이런게 있다.

PRIMARY KEY - 중복x 고유하는 대표
not null - 빈칸일수 없다
unique - 중복 금지 
default - 값안주면 기본 값 (null일떄 기본값 세팅)
check - 조건이 참인경우
foreign kry - 참고 ( 다른테이블에 있는 값만)

cascade - 부모 자식 다 삭제.
